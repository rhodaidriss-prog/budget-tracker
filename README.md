Budget Tracker
Project Description

This project is a simple Budget Tracker that allows users to record and view their expenses.

For this visual design challenge, I improved the existing Budget Tracker using CSS. The main focus was creating a clean, professional, and user-friendly interface without adding unnecessary functionality.

Project Files

index.html – Contains the structure and content of the Budget Tracker.

style.css – Contains all the visual styling, including colors, typography, form styling, table styling, spacing, borders, and layout.

README.md – Explains the project and the design choices.

Design Choices
1. Color Palette

I used a green, white, and light gray color palette.

Green is used for the main headings, buttons, and table header. White is used for the cards and form areas, while light gray is used as the page background.

The colors were chosen to create a clean and professional appearance suitable for a budgeting application.

2. Typography

I used two Google Fonts:

Merriweather for headings.

Open Sans for body text, labels, form elements, buttons, and table content.

This creates a clear visual hierarchy and improves readability.

3. Add Expense Form

The Add Expense form has been styled with:

Consistent spacing

Padding inside inputs

Borders

Rounded corners

Focus effects

A consistent green button

A hover effect on the button

These styles make the form easier to use and visually consistent with the rest of the application.

4. Expense Table

The Expense Table has been improved with:

A green table header

White header text

Padding inside table cells

Borders between rows

Alternating row colors

Hover effects

Rounded corners

Alternating row colors make the expense information easier to scan and read.

5. CSS Box Model

The CSS Box Model was intentionally used throughout the project.

Margin is used to create space between sections.

Padding is used to create space inside cards, inputs, buttons, and table cells.

Borders are used to define cards, inputs, and table areas.

Border-radius is used to create rounded corners.

The page heading, Add Expense form, and Expense Table are displayed as separate card-like sections.

6. Responsive Design

A small responsive design section was added so that the Budget Tracker remains usable on smaller screens.

On smaller devices, the form changes from two columns to one column and the table can scroll horizontally when necessary.

Conclusion

The existing Budget Tracker was visually improved using CSS while keeping the original purpose of the application.

The final design uses a consistent color palette, custom typography, styled forms and tables, and the CSS Box Model to create a polished and user-friendly interface.
